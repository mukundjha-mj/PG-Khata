# PG Manager Pro

An admin application for managing PG properties, rooms, tenants, rent billing,
payments, meter readings, reports, and notifications.

## Development

Install [Bun](https://bun.sh), then run:

```sh
bun install
bun run dev
```

Create a production build with:

```sh
bun run build
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
